# OwnDash 0.14.0 Beta 5

Beta 5 focuses on safer display handling, clearer device diagnostics, responsive lifecycle screens and a more deliberate update experience.

## Highlights

- New always-available **Display & Device** center with passive, sanitized diagnostics.
- Verified direct-USB profile handling with explicit multi-device ambiguity protection instead of choosing by enumeration order.
- **Software dimming** from 10–100% without sending unverified hardware-brightness commands.
- Clear separation between configured/selected output and the output that is actually active.
- Responsive system-state screens for ultra-portrait, portrait, near-square and landscape displays while preserving the physically accepted 480×1920 VSDISPLAY composition.
- State-aware time display: lock keeps live clock/date, idle keeps the live clock, and static standby/shutdown/restart/disconnected screens show no stale time.
- 48-image CI preview matrix covering six system states across eight representative resolutions.
- Manual **Check for updates** action with clear up-to-date/update/error feedback; automatic background failures remain silent and OwnDash still never installs updates automatically.

## Validation

- The release-candidate automated suite contains 595 tests before the final tagged build.
- System-state lifecycle behavior was exercised on the maintainer's Bazzite/KDE + 480×1920 VSDISPLAY setup; the final Beta 5 AppImage receives one additional release-candidate hardware smoke test before publication.
- Non-reference system-state aspect ratios are structurally tested and visually rendered in CI; broader community hardware evidence remains welcome.
- The official AppImage must pass the Debian 12 / GLIBC 2.36 compatibility gates from the release tag before publication.

## Release asset

`OwnDash-0.14.0-Beta-5-x86_64.AppImage`

The SHA-256 is generated from the exact final tagged AppImage and added here before the GitHub release is published.

## Known limitations

- Physical mounting orientation is not detected over direct USB; output uses the configured dashboard orientation.
- Hardware brightness control remains disabled for the current `33C3:0E02` ArtInChip / VSDISPLAY transport because a safe control mechanism has not been verified.
- Expansion Screen Mode and persistent startup-image/video writes remain disabled until separate real-hardware verification proves them safe.
- Mixed-DPI and compositor-specific fullscreen placement still benefit from additional real-system validation.
- OwnDash remains beta software.

## Installation

Download the attached x86-64 AppImage, make it executable, and launch it:

```bash
chmod +x OwnDash-0.14.0-Beta-5-x86_64.AppImage
./OwnDash-0.14.0-Beta-5-x86_64.AppImage
```

Python does not need to be installed separately when using the official AppImage.
