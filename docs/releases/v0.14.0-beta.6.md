# OwnDash 0.14.0 Beta 6

Beta 6 fixes standby/resume recovery and unifies the six reference status screens.

## Highlights

- Standby artwork is transmitted within a bounded logind sleep-delay window before suspend.
- Automatic USB reconnection retries for approximately 100 seconds, accommodating slow controller recovery.
- Stale USB enumeration entries no longer incorrectly trigger the multiple-display warning. Genuinely separate compatible displays remain protected against arbitrary selection.
- All six 480×1920 reference screens now share consistent frame and lower HUD geometry, retaining their individual colours and symbols.
- Updated README previews and clearer lifecycle/USB failure logs.

## Validation and limits

- 615 automated tests, including delayed recovery, stale callbacks, sleep-delay cleanup, USB enumeration and shared screen geometry.
- The maintainer confirmed standby artwork and automatic return to live widgets after a real suspend/resume cycle using Standby-Fix 3; Beta 6 includes that same implementation.
- Recovery can still be slow: the affected USB controller previously re-enumerated the display about 43 seconds after wake, with permissions becoming available later. Allow up to 100 seconds.
- The release build must pass the Debian 12 startup and GLIBC 2.36 compatibility gates before publication.
- The CI preview matrix covers six states at eight resolutions. Broader hardware testing remains welcome.
- Existing hardware-control limitations remain: no unverified hardware-brightness, Expansion Screen Mode or persistent startup-media writes. OwnDash remains beta software.

## Installation

Download `OwnDash-0.14.0-Beta-6-x86_64.AppImage`, make it executable and launch it:

```bash
chmod +x OwnDash-0.14.0-Beta-6-x86_64.AppImage
./OwnDash-0.14.0-Beta-6-x86_64.AppImage
```

Python does not need to be installed separately. Beta 5 remains available as a previous release.
