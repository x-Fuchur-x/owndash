# OwnDash 0.14.0 Beta 4

This beta improves display switching, proportional scaling and the pause screen on small dashboards, and adds optional update notifications.

## Highlights

- Widgets scale as a whole, including fonts, borders, spacing and effects.
- Fitted geometry and content scaling persist across saves, reloads and theme changes.
- Correct monitor selection and HiDPI resolution reporting, plus automatic editor fitting.
- Adaptive portrait and landscape pause screens with clearer typography and a subtle blue glow on tall displays.
- Contextual status when OwnDash closes or output switches, with the running version and German/English localization.
- USB displays receive a pause image before output switches away.
- Improved USB write validation and disconnect handling.
- Optional, non-blocking update notifications; no automatic download or installation.

## Validation

- 371 automated tests passed for the Beta 4 release state.
- Beta 4 was tested by the maintainer on Bazzite with the installed VSDISPLAY USB display and standard-monitor output.
- The published AppImage was built from the official `v0.14.0-beta.4` tag.
- The official AppImage targets the Debian 12 / GLIBC 2.36 compatibility baseline.

## Known limitations

- Physical mounting orientation is not detected over USB; output uses the configured dashboard orientation.
- USB brightness control is not enabled for the current VSDISPLAY controller because a compatible control transport has not been verified.
- Persistent firmware boot-image replacement is not supported directly by OwnDash yet.
- OwnDash remains beta software.

## Installation

Download the attached x86-64 AppImage, make it executable, and launch it:

```bash
chmod +x OwnDash-0.14.0-Beta-4-x86_64.AppImage
./OwnDash-0.14.0-Beta-4-x86_64.AppImage
```

Python does not need to be installed separately when using the official AppImage.
