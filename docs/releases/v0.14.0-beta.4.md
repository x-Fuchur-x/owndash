# OwnDash 0.14.0 Beta 4

This beta improves display switching, proportional scaling and the pause screen on small dashboards.

## Highlights

- Widgets scale as a whole, including fonts, borders, spacing and effects.
- Fitted geometry and content scaling persist across saves, reloads and theme changes.
- Correct monitor selection and HiDPI resolution reporting, plus automatic editor fitting.
- Adaptive portrait and landscape pause screens with clearer typography and a subtle blue glow on tall displays.
- Contextual status when OwnDash closes or output switches, with the running version and German/English localization.
- USB displays receive a pause image before output switches away.
- Improved USB write validation and disconnect handling.
- Optional, non-blocking update notifications; no automatic download or installation.

## Validation

- 371 automated tests passed after the Beta 4 version update.
- The preceding feature build was tested successfully by the maintainer on Bazzite with the installed VSDISPLAY and standard-monitor output.
- The Beta 4 AppImage must be built from the Beta 4 tag; the earlier Beta 3-labeled artifact is not the release binary.

## Known limitations

- Physical mounting orientation is not detected over USB; output uses the configured dashboard orientation.
- USB brightness control and persistent firmware boot-image replacement are not enabled for this VSDISPLAY variant.
- OwnDash remains beta software.

## Installation

Download the attached x86-64 AppImage, make it executable, and launch it. Python does not need to be installed separately. The official build targets the Debian 12 / GLIBC 2.36 baseline.
