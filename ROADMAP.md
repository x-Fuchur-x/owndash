# OwnDash roadmap

## 0.9.7 — Background Runtime & Aurora Studio

- Animated dashboards continue when the editor window is closed
- System-tray runtime with reopen / stop display / full quit actions
- User-controllable background-running behavior
- Lighter adaptive USB cadence (~10 FPS motion / ~3 FPS static)
- Leaner motion JPEG quality
- Custom Aurora colors, speed and intensity
- Aurora controls shown contextually to keep the UI clean

## Next

- Measure real-device CPU use and tune the render path further
- Investigate a single-encode rotated-frame pipeline to remove duplicate JPEG work
- More instrument styles and animation presets
- Sensor-driven rules and alerts
- Dashboard/page management
- Packaging and stability work toward 1.0
